# Contributing

Thanks for considering a contribution. This library is intentionally small and dependency-free.

1. Open an issue describing a bug or suggesting a feature before making significant API changes.
2. Keep all contributions general-purpose. Do not submit proprietary project code, third-party assets, personal data, tokens, or secrets.
3. Match the existing Luau naming style and keep the public API documented in `docs/API.md`.
4. Test changes in Roblox Studio, including mouse/touch and disabled-button behavior where possible.
5. In your pull request, explain what changed, why, and how you tested it.

All contributions must be compatible with the repository's MIT license.
